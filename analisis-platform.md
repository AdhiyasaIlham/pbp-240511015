# Analisis Komparatif Platform Web, Desktop, dan Mobile

## 1. Komparatif Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript | C#, C++, Java, Python | Kotlin, Java, Swift, Dart |
| Arsitektur | Menggunakan browser untuk menampilkan antarmuka dan berkomunikasi dengan server | Berjalan pada sistem operasi komputer dan dapat memproses data secara lokal atau melalui server | Berjalan pada sistem operasi perangkat mobile dan dapat terhubung dengan layanan server |
| Cara distribusi | Dipublikasikan melalui web server dan diakses menggunakan URL | Dibagikan melalui installer, situs resmi, atau toko aplikasi | Didistribusikan melalui Google Play Store, Apple App Store, atau metode instalasi lain yang didukung |
| Keunggulan | Mudah diakses melalui browser dan pembaruan dapat dilakukan dari sisi server | Dapat memanfaatkan sumber daya komputer dan mendukung pekerjaan yang membutuhkan integrasi sistem operasi | Praktis digunakan saat bepergian dan dapat memanfaatkan fitur perangkat seperti kamera serta GPS |
| Keterbatasan | Beberapa fungsi bergantung pada koneksi internet dan kemampuan browser | Memerlukan instalasi dan dapat memiliki perbedaan kompatibilitas antar sistem operasi | Perlu mempertimbangkan kapasitas baterai, ukuran layar, serta perbedaan spesifikasi perangkat |
| Contoh aplikasi | Gmail versi web, Google Docs | Visual Studio Code, VLC Media Player, Microsoft Office, Discord | Google Maps, WhatsApp, Instagram, Facebook, YouTube |
